하루 공부계획표 앱 설치 방법
(처음 한 번만, 컴퓨터에서 하는 것을 권장함. 약 20분)

[1] Firebase 준비 (데이터 저장소)
1. console.firebase.google.com 접속, 구글 계정으로 로그인
2. 프로젝트 추가 > 이름 입력 (예: study-planner) > Google 애널리틱스는 꺼도 됨
3. 왼쪽 메뉴 빌드 > Authentication > 시작하기 > 로그인 방법 탭 > 익명 > 사용 설정 > 저장
4. 빌드 > Firestore Database > 데이터베이스 만들기
   - 위치: asia-northeast3 (서울)
   - 프로덕션 모드로 시작
5. Firestore의 규칙 탭에서 기존 내용을 모두 지우고 firestore.rules 파일 내용을 붙여 넣은 뒤 게시
6. 프로젝트 설정(톱니바퀴) > 일반 > 내 앱 > 웹 아이콘(</>) > 앱 이름 입력 > 앱 등록
   (Firebase 호스팅 설정은 체크하지 않음)
7. 화면에 나오는 firebaseConfig의 값(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)을
   config.js에 넣기 (이미 채워져 있음)

[2] GitHub Pages로 주소 만들기
1. github.com 가입 후 로그인
2. 오른쪽 위 + > New repository > 이름 입력 (예: study-planner) > Public 선택 > Create repository
3. uploading an existing file 링크 클릭 > 이 폴더의 파일을 모두 끌어다 놓기 (수정한 config.js 포함) > Commit changes
4. 저장소의 Settings > Pages > Branch를 main, 폴더는 / (root)로 선택 > Save
5. 1~2분 뒤 화면 위에 나오는 주소로 접속 (예: https://아이디.github.io/study-planner/)
6. Firebase로 돌아가 Authentication > 설정 > 승인된 도메인 > 도메인 추가 > 아이디.github.io 입력

[3] 사용 시작
1. 부모님 폰에서 위 주소 열기 > 새 가족 계획표 만들기
2. 편집 탭에서 할 일과 일정 입력
3. 편집 탭 아래 가족과 공유의 QR을 아이 태블릿 카메라로 찍기 > 아이 모드로 열림
4. 다른 보호자 기기는 부모용 링크로 열기

[4] 홈 화면에 앱처럼 추가
- 갤럭시 (크롬): 오른쪽 위 점 세 개 > 홈 화면에 추가 (또는 앱 설치)
- 갤럭시 (삼성 인터넷): 아래 메뉴 > 현재 페이지 추가 > 홈 화면
- 아이폰/아이패드 (사파리): 공유 버튼 > 홈 화면에 추가
- 반드시 가족 링크(또는 QR)로 한 번 연 화면에서 추가해야 바로 내 계획표가 열림

[참고]
- 링크와 가족 코드가 곧 열쇠라서 가족 밖에는 보내지 않기
- config.js의 Firebase 설정값은 공개되어도 되는 값 (보안은 Firestore 규칙과 가족 코드로 지킴)
- 가정에서 쓰는 정도는 Firebase 무료 요금제(Spark) 범위 안에서 충분함
- 앱을 고치고 싶으면 GitHub 저장소에서 파일을 다시 올리면 1~2분 뒤 반영됨
